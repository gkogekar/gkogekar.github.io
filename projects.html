Open-Source Contributions to Cantera (Thermochemistry, Reacting Flows & Reactor Modeling)

Contributed to the Cantera multiphysics simulation framework for thermodynamics, chemical kinetics, and reacting flow systems with emphasis on real-gas modeling, catalytic reactors, and solver-level improvements.

Key Contributions:

  • Implemented and extended real-gas thermodynamics using Peng–Robinson equation of state for high-pressure reacting systems
  • Developed 1D flame and non-ideal combustion models with detailed chemical kinetics
  • Formulated catalytic and packed-bed reactor models within multiphysics simulation infrastructure
  • Integrated surface chemistry, adsorption, and diffusion-controlled reaction mechanisms
  • Contributed multiple pull requests across thermochemistry and reactor modules (solver + model enhancements)

Boundary-Layer Modeling & Reduced Order Modeling for Reactive Incineration Systems

Developed a computational boundary-layer framework for reactive incinerator systems involving coupled transport–reaction physics with detailed chemistry (including PFAS degradation pathways). Extended the formulation to include reduced-order modeling for field reconstruction and dimensionality reduction.

Key Contributions:

  • Derived Von Mises–transformed boundary-layer governing equations for reacting flow systems
  • Implemented coupled CFD–chemistry solver for reactive transport simulation
  • Developed numerical framework for incineration modeling with detailed chemical kinetics
  • Applied model to PFAS degradation chemistry in high-temperature environments
  • Constructed ROM workflow using snapshot-based decomposition of CFD solution fields
  • Performed exploratory reduced-order analysis of velocity and scalar fields using Jupyter notebooks

Quasi-2D Catalytic Packed-Bed Reactor Modeling

Developed a quasi-two-dimensional reactor modeling framework for catalytic packed-bed systems enabling efficient simulation of coupled transport and heterogeneous reaction phenomena in porous media.

Key Contributions:

  • Formulated coupled mass, energy, and species transport equations in porous catalytic media
  • Developed quasi-2D reactor representation for reduced computational complexity
  • Integrated detailed heterogeneous reaction kinetics using Cantera framework
  • Applied model to catalytic systems including ammonia synthesis-type reaction environments
  • Enabled reactor-scale simulation with preserved physicochemical fidelity

Thermodynamic Modeling: Peng–Robinson Equation of State

Developed a theoretical and computational formulation of the Peng–Robinson equation of state for modeling non-ideal thermodynamic behavior in high-pressure reacting systems.

Key Contributions:

  • Derived thermodynamic formulation of Peng–Robinson EOS for real-gas systems
  • Analyzed applicability in combustion and high-pressure reactor environments
  • Established framework for integration into multiphysics CFD simulations
  • Documented formulation for use in reactor-scale modeling workflows
